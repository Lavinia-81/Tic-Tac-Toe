# ❌⭕ Tic‑Tac‑Toe
HTML • CSS • JavaScript — Classic Strategy Game  
Live Demo: https://lavinia-81.github.io/Tic-Tac-Toe/

A simple and responsive Tic‑Tac‑Toe game built using vanilla JavaScript, HTML, and CSS.
This project was created early in my learning journey to explore game logic, DOM manipulation, and interactive UI design.

---

## Overview
Tic‑Tac‑Toe is a classic two‑player strategy game where players take turns placing X and O on a 3×3 grid.
The first player to align three marks horizontally, vertically, or diagonally wins.
If all cells are filled without a winner, the game ends in a draw.

This project demonstrates foundational front‑end development concepts such as:
- event listeners
- dynamic DOM updates
- game state management
- win/draw condition checking
- responsive UI design

## How to Play
- Open index.html in your browser.
- The 3×3 game board will appear.
- Players take turns clicking on empty cells to place X or O.
- The first player to align three marks wins.
- If all cells are filled and no winner is found, the game ends in a draw.
- Click Restart to start a new game.
